# Concurrency in .NET 10

## English

*Concurrency in .NET 10* introduces the core principles and practical techniques of concurrent and asynchronous programming in .NET. Starting with threads and asynchrony, it covers `Task`, `async`/`await`, exception handling and cancellation, synchronization, thread safety, parallel processing, asynchronous streams, and asynchronous API design.

This website provides free previews in English and Traditional Chinese. Chapters 1–5 are available in full; Chapters 6–11 provide topic summaries. Please see the formally published edition for the complete book.

Read: [dotnetconcurrency.huanlin.cc](https://dotnetconcurrency.huanlin.cc/)
